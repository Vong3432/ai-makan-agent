# Goals & Non-goals

## Goals

- Recommend meals per meal slot, personalised to each user's habits, likes/dislikes, and allergies.
- Learn continuously from conversational feedback ("this one quite good", "too oily").
- Respect where the user is willing to go (location + travel radius).
- Work from any MCP host; multi-user from day one.
- Keep running cost minimal.

## Non-goals (for now)

- Live GPS / device location.
- Ordering or delivery integration.
- Menu-level data per restaurant (we infer from place type + LLM knowledge).
- Social features or sharing preferences between users.
